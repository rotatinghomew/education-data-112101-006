# 课程销售退款与续单收入的期间核算

本地资料用于理解课程销售退款期间核算所涉及的记录关系。文件均为合成数据，标识符不对应真实个人、机构或账号。

## 目录

- `data/`：UTF-8 编码、首行为字段名的逗号分隔资料。空字段表示资料未提供，不代表数值为零或业务状态已否定。
- `ledger/`：期间核算工具（无第三方依赖），把两种核对视角固化为可重复运行的代码。
- `tests/`：检查资料文件可读取和格式结构，并核对核算口径的关键数字。

日期使用 ISO 8601 写法；时间字段为空时表示该记录没有提供时间。金额和计数字段以文本保存，具体解释须结合字段名及记录上下文。

## 核算口径

订单额、服务履约与实际现金是三个相互独立的口径，不合并为单一“收入”数字。

- **销售表现**：按订单创建时间（`ordered_at`）归入销售期。无父单为新购；父单课程相同为续单（新的服务周期，按全额计入）；父单课程不同为升级（如体验课升级为正式课程，只计相对父单金额的增量），同一笔原有服务不会随子单全额在新签总额里重复出现。
- **资金变化**：按实际结算时间（`settled_at`）归期。`reversal_of` 非空的付款行是对被引用付款的冲正记录，在发生期间计为负向资金；已结算退款同理。尚未结算的退款与仍有争议的订单单独列示，不计入已发生的现金流。
- **服务履约**：按下单日匹配当时有效的课程版本，以服务单位计量。升级链中已被子单取代的父单不重复计单位；部分退款不抹掉仍然有效的服务；争议订单保留但加以标记。
- **口径还原**：`--as-of` 按当时可见的交易状态重算报告（退款在结算日前视为未结算），已发布的复盘结果可据此还原；`explain` 比较两个口径日期，逐项说明变化来自哪笔交易。

## 运行与检查

需要 Python 3.11 或更高版本，无第三方运行依赖。运行 `python3 -m unittest discover -s tests` 检查合成资料是否可读并核对核算口径。

```bash
python3 -m ledger report                          # 经营复盘报告（销售/履约/资金分列）
python3 -m ledger report --as-of 2026-03-31       # 按当时可见状态还原报告
python3 -m ledger report --json                   # 机器可读输出
python3 -m ledger explain --from 2026-02-15 --to 2026-03-31   # 解释两口径日之间的变化来源
python3 -m ledger order O-2                       # 单笔订单追溯（父子链、课程版本、付款人、收退款）
python3 -m ledger validate                        # 仅列出数据质量提示
```
